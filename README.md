# Automated LLM-Driven Actionable Recourse Engine

An AI and prompt-engineering framework that translates numerical counterfactual targets into structured, actionable student and tutor recommendations using Large Language Models (Qwen, Phi, Mistral).

## Overview & Architecture
This prototype is built based on research from my M.Tech Thesis at IIITDM Kancheepuram.

- **Full M.Tech Thesis Report (PDF):** [View Report on Google Drive](https://drive.google.com/file/d/1ffUG9IVKV_fkPFkCD3z5Sgh8aMau01ei/view?usp=drivesdk)
- **Key Focus:** Prompt Engineering, LLM-based Intervention, Counterfactual Reasoning, and ML/DL Automation Pipelines.
